# Лабораторная работа №1 – Функции ввода/вывода, условный оператор

В работе представлены три программы: калькулятор площади треугольника, конвертер единиц расстояния и определение високосного года.

## Среда разработки

Язык программирования: Python.

## Инструкция по работе

**Калькулятор площади треугольника.** По запросу программы введите три стороны. Если треугольник существует, программа выведет его площадь с двумя знаками после запятой.

**Конвертер расстояния.** Введите расстояние, исходную и целевую единицы измерения. Доступны км, м, см, мм, mi и yd.

**Определение високосного года.** Введите год. Программа выведет, является ли он високосным.
